Autopeças Digital - Web App de Extensão (UFMS)

Este projeto é um Web App (Mobile First) desenvolvido como parte das ações de extensão do Projeto Integrador de TI da UFMS.

Objetivo
Fornecer uma ferramenta de consulta rápida para os funcionários de uma loja de autopeças, abordando diretrizes de proteção de dados (LGPD) e o descarte correto de lixo eletrônico durante a rotina de trabalho, substituindo a antiga cartilha estática em PDF.
Tecnologias Utilizadas
- HTML5 (Estruturação)
- CSS3 (Estilização responsiva e Flexbox)
- JavaScript Vanilla (Lógica de navegação e estrutura `switch/case`)
Como executar
Não é necessária a instalação de nenhum software. Basta baixar o arquivo `index.html` e abri-lo em qualquer navegador web (Chrome, Edge, Firefox). Para melhor experiência, abra no modo dispositivo móvel (F12 > Toggle Device Toolbar).
